# Marlonreic.github.io

Portfolio of Marlon Reichert — traffic data analyst who builds the instruments
he works with.

Live at **https://marlonreic.github.io**

The page covers the heads-up display I built for classifying vehicles out of
recorded traffic video (rebuilt on the page at its true size, running), the
design reasoning behind each element, and a chart of my own detector's measured
error by hour of day.

Source for the counting tooling itself:
[traffic-count-hud](https://github.com/Marlonreic/traffic-count-hud).
